# IconButton

Botão só de ícone, com alvo de 44px e rótulo acessível obrigatório.

- Forneça `icon` e `label` ("Voltar", "Notificações", "Salvar nos favoritos", "Conversar com Carlos").
- `surface` (padrão, redondo com borda `line`) na barra superior; `soft` (`plum-soft`) para contato dentro de cards; `solid` (`plum`) para o botão de filtros ao lado da busca.
- `dot` mostra o ponto de notificação em `alert`.
