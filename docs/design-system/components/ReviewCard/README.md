# ReviewCard

Uma avaliação de cliente, com tags e a resposta do prestador.

- Forneça `author` (primeiro nome e inicial), `initials`, `date`, `service`, `rating`; opcionais `text`, `tags` e `reply` (`{ author, text }`).
- Avatar de cliente é círculo. A resposta do prestador fica numa caixa `surface-inset` abaixo.
- Só quem contratou pelo app avalia; não mostre avaliações sem pedido vinculado.
