# Avatar

Iniciais da pessoa sobre um tom da paleta, ou a foto quando existir.

- Forneça `initials`, `name` (rótulo acessível), `tone` e `size`.
- `kind="provider"` (padrão): quadrado arredondado com raio de 31% do lado. `kind="client"`: círculo. A forma diferencia quem oferece de quem contrata.
- Tamanhos usados: 96 (perfil), 72 (avaliar), 60 (card de busca), 48 (carrossel), 44 (listas), 38 (avaliações), 40 (cliente no pedido).
- Escolha o tom de forma estável pelo id da pessoa.
