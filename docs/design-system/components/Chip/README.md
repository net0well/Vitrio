# Chip

Opção selecionável em pílula: filtros, categorias, bairros, tags de avaliação.

- Forneça o rótulo como filho e `selected`/`onChange` (ou `defaultSelected`).
- `solid` (padrão): filtros da busca e escolha única de serviço; selecionado vira `plum` com check `plum-accent`.
- `soft`: seleção múltipla (bairros atendidos, tags da avaliação); selecionado vira `plum-soft` com borda `plum`.
- Linhas de chips rolam na horizontal na busca e quebram linha em formulários.
- Não: chips como navegação, mais de 8 opções sem busca.
