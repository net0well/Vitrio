# Switch

Liga/desliga com efeito imediato, em linha com rótulo e descrição.

- Forneça `label`, `description` opcional e `checked`/`onChange` (ou `defaultChecked`).
- A descrição diz o efeito do estado atual: "Você aparece em 'Atende hoje'", "A cliente compra o material".
- Trilho desligado em `line-strong`, ligado em `plum`; o botão vira `plum-accent` quando ligado.
- Não: switch para ações que precisam de confirmação (use `Button`).
