# HeroCard

Card de destaque em superfície `hero`, com uma chamada e uma ação.

- Forneça `title`, `text`, `actionLabel`, `href`; opcionais `tag` (selo `lime`) e `icon` (desenho grande decorativo a 30%).
- Um por tela, no máximo. Use para atalhos de alto valor ("Imprevisto em casa? Ver disponíveis"), nunca para propaganda.
