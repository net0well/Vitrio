# ActionBar

Base fixa das telas de tarefa, com a ação principal em largura total.

- Forneça os botões como filhos (um `primary`, opcionalmente um `secondary` à esquerda) e `note` opcional com a regra que tranquiliza.
- Exemplos de nota: "Pedir orçamento é grátis e sem compromisso.", "O cliente verá esse registro no pedido."
- Fica fixa no rodapé com a área do gesto de início; substitui a `BottomNav`.
