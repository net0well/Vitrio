# TextArea

Texto longo com rótulo, dica e contador.

- Forneça `label` e `value`/`onChange(valor)` (ou `defaultValue`); `maxLength` padrão 500 (avaliação usa 400).
- Usado em: descrição do pedido, mensagem do orçamento, comentário da avaliação, motivo da diferença de valor.
- A dica ensina a preencher bem: "Quanto mais detalhes, mais preciso o orçamento."
