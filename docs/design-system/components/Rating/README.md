# Rating

Nota de um prestador ou de uma avaliação, sempre com o número.

- `compact` (padrão): uma estrela, a nota com uma casa decimal (4,9), a contagem entre parênteses e `meta` opcional (distância e bairro).
- `stars`: cinco estrelas, para cabeçalhos de avaliação; arredonda para a estrela inteira mais próxima e anuncia "Nota 4,6 de 5".
- Prestador sem avaliações não mostra 0,0: use o `Badge` "Novo no Vitrio".
