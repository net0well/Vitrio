# BottomNav

Navegação inferior das telas de topo, com 4 destinos.

- Forneça `items` (`{ icon, label, href, current }`); exatamente um com `current`.
- Cliente: Início, Buscar, Pedidos, Conta. Prestador: Painel, Pedidos, Agenda, Meu perfil.
- Nunca aparece junto com `ActionBar`; telas de tarefa escondem a navegação.
