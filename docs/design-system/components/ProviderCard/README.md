# ProviderCard

Resultado de busca: quem é, quão bem avaliado, quão perto e a partir de quanto.

- Forneça `name`, `initials`, `profession`, `rating`, `reviews`, `neighborhood`, `href`; opcionais `distance` (só com GPS ativo), `verified`, `badges` (até 3) e `priceFrom` (sem ele, mostra "Sob orçamento").
- O card inteiro é um link para o perfil; "Ver perfil" é só indicação visual.
- Ordem dos selos: MEI verificado, Atende hoje, tempo de resposta.
- Não: esconder a nota, mostrar endereço, mais de 3 selos.
