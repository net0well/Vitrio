# SearchField

Campo de busca de serviços com botão de enviar.

- Forneça `onSubmit(termo)`; opcionalmente `defaultValue` e `placeholder` (padrão: "Eletricista, diarista, pintor…").
- Use na Início e no topo da Busca. O rótulo é lido por leitores de tela mesmo sem aparecer.
- A busca respeita a localização ativa (GPS ou cidade escolhida); não peça cidade dentro do campo.
