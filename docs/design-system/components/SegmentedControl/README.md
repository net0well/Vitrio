# SegmentedControl

Escolha única entre 2 e 3 opções curtas, num trilho `track`.

- Forneça `label` (lido por leitores de tela), `options` (`{ value, label }`) e `value`/`onChange` (ou `defaultValue`).
- Usado em: dia do serviço (Hoje / Amanhã / Escolher data), tipo de orçamento (Valor fechado / Visita técnica), abas de listas curtas.
- Mais de 3 opções ou rótulos longos: use `Chip`.
