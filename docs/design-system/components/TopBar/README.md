# TopBar

Barra superior de 44px: voltar, título centralizado e ação opcional.

- Forneça `title` e `backHref` ou `onBack`; `trailing` para uma ação (um `IconButton` ou `Button` ghost como "Pular").
- Título curto com o nome da tarefa: "Pedir orçamento", "Responder pedido", "Confirmar pagamento".
- Em fluxos que fecham (avaliar), use `backIcon="x"` e `backLabel="Fechar"`.
