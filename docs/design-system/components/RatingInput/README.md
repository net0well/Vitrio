# RatingInput

Seletor de nota de 1 a 5 estrelas, com a palavra correspondente.

- Forneça `value`/`onChange(nota)` (ou `defaultValue`).
- Cada estrela é um botão de 48px anunciado como "1 estrela" … "5 estrelas"; a palavra (Péssimo, Ruim, Regular, Bom, Excelente) aparece abaixo.
- Só na tela Avaliar serviço, centralizado, logo abaixo da pergunta "Como foi o serviço?".
