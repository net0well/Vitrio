# QuoteCard

Orçamento recebido pelo cliente, com valor, condições e a decisão.

- Forneça `from` (primeiro nome), `price`, `validity` ("Válido até qui 29/10, 13:00"), `rows` (visita, material, duração), `message`, `onAccept`, `onDecline`.
- É o único card da tela com `shadow-md` e borda `plum`: é a decisão da tela.
- Ao aceitar, o endereço completo vai para o prestador; diga isso na tela antes do botão quando for a primeira vez.
