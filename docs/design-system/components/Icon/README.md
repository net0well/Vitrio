# Icon

Ícone do conjunto próprio do Vitrio, desenhado em traço com a cor do texto ao redor.

- Forneça `name` (um dos nomes de `ICON_NAMES`) e, se preciso, `size` (padrão 20) e `strokeWidth` (padrão 2; use 2.2–2.4 entre 14 e 18px).
- Decorativo por padrão (`aria-hidden`). Passe `label` só quando o ícone estiver sozinho e carregar significado.
- `filled` só para a estrela; para nota use `Rating`, que já aplica `amber` e `amber-edge`.
- Não: emoji, logos de terceiros (WhatsApp, Pix), ícones de outras bibliotecas misturados.
