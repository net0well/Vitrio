# Badge

Uma ou duas palavras de status ou atributo, em pílula.

- Forneça o texto como filho e `tone`. Opcionais: `icon`, `dot`.
- Tons: `verified` (MEI verificado, com `shield-check`), `brand` (Atende hoje, tags), `neutral` (Responde em ~15 min, Sob orçamento), `warning` (Válido por 48 h, Novo no Vitrio), `accent` (Novo, Disponíveis agora), `danger` (Cancelado, Contestado), `info` (Aguardando orçamento).
- Status de pedido sempre com palavra; a cor reforça, não substitui.
