# Licenças das fontes

As duas famílias do Vitrio são livres sob a SIL Open Font License 1.1: podem ser usadas, embutidas no app e redistribuídas junto dele, desde que a licença vá junto e as fontes não sejam vendidas sozinhas.

- `OFL-BricolageGrotesque.txt` — Bricolage Grotesque, © The Bricolage Grotesque Project Authors.
- `OFL-PlusJakartaSans.txt` — Plus Jakarta Sans, © The Plus Jakarta Sans Project Authors.

Inclua os dois arquivos na tela de licenças do app (no Flutter, registre-os com `LicenseRegistry.addLicense`).
