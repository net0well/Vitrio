# Planos

Planos gerados pelo `/plan` a partir das specs aprovadas, um arquivo por spec, com o mesmo nome (`005-pedidos-e-orcamentos.md`). O plano mapeia cada critério de aceite para passos de implementação na Clean Architecture com Controllers e lista riscos e perguntas abertas.

Planos são documentos vivos: se a implementação sair do caminho, pare, atualize o plano e siga. Assim como as specs, eles nunca são citados em código, testes, branches ou commits.
